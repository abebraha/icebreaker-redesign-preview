# Icebreaker — redesign preview

Static preview of the icebreakerbd.com redesign described in the *Icebreaker Website Blueprint*. **This is not the live site.**

Pages: `index.html` (home), `pricing.html`, `results.html`, `careers.html` (job board — jobs are a snapshot of `/api/jobs`; production fetches live). Plain HTML/CSS/JS — no build step. Tracker figures marked “sample” are illustrative; the real version connects to the KPI tracker.

Fonts load from Google Fonts (Archivo + Inter). All other assets are in `assets/`.
